# NAI Korea 상업용 부동산 통합 지도

NAI Korea의 상업용 부동산 물건 DB(호텔 · 물류센터 · 오피스 · 데이터센터)를
카카오맵 위에서 조회·검색·필터·수정하는 단일 페이지 웹앱입니다.
빌드 도구 없이 정적 파일만으로 동작하며, GitHub Pages에서 서빙됩니다.

- 배포 주소: <https://rnjswnsdh-lab.github.io/nai-asset-map/>
- 접속하려면 **접속코드**가 필요합니다. 코드가 없으면 물건 데이터는 1건도 로드되지 않습니다.

## 동작 방식

1. 첫 화면에서 접속코드를 입력합니다.
2. 브라우저가 코드를 SHA-256으로 파생해 접근 토큰을 만들고, 그 토큰을 이 브라우저의
   `localStorage`에만 저장합니다. 코드·토큰의 평문은 소스에 없습니다.
3. 토큰이 유효하면 Google Apps Script 웹앱(비공개 Google 시트)에서 물건 목록을 받아
   카카오맵 마커와 목록으로 렌더링합니다.
4. 물건을 수정·추가·삭제하면 같은 API로 시트에 즉시 반영되고, 실패 시 브라우저 대기열에
   남겨 두었다가 다음 접속 때 다시 전송합니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조와 접속코드 게이트 |
| `app.js` | 지도·필터·검색·상세·수정·동기화 로직 |
| `style.css` | 반응형 스타일 (PC 우측 패널 / 모바일 하단 시트) |
| `config.js` | 카카오 JavaScript 키 · 동기화 API 주소 설정 |

## 보안 메모

- 이 저장소에는 **물건 데이터가 포함되어 있지 않습니다.** 데이터는 비공개 Google 시트에만 있습니다.
- 접속코드와 접근 토큰은 저장소에 커밋되지 않으며, 사용자가 화면에서 직접 입력합니다.
- 앱은 엣지(Edge)·크롬·사파리 최신 버전에서 동작합니다. 접속코드 파생에 Web Crypto를 쓰므로
  HTTPS(GitHub Pages) 또는 `localhost`에서만 접속이 가능합니다.

## 카카오맵 키 설정

`config.js`의 `KAKAO_JS_KEY`에 카카오 디벨로퍼스 JavaScript 키가 설정되어 있고,
해당 키에는 웹 도메인 `https://rnjswnsdh-lab.github.io`가 등록되어 있어야 지도 타일이 표시됩니다.
키가 없거나 도메인이 등록되지 않으면 좌표 미리보기 모드로 떨어집니다.
