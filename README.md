# Open AI Asset Bridge

NAI Korea의 상업용 부동산 물건 DB(호텔 · 물류센터 · 오피스 · 데이터센터 · 화주·임차수요)와
투자자 풀(SI·화주 / FI)을 카카오맵·카드 목록 위에서 조회·검색·필터·수정하는 단일 페이지 웹앱입니다.
**로그인 후 첫 화면은 `🏠 홈`(딜 브릿지 대시보드)** 이고, 지도·SI/FI·밸류에이션은 상단 탭에서 이어집니다.

### ➕ 물건등록 — TM / IM / 직접 3가지

| 권한 | 처리 |
| --- | --- |
| **관리자** | `assets`에 **즉시 반영**(`source: 웹 직접등록`, `status_group: 검토중`). 저장 후 목록·지도에 바로 나타납니다 |

### 📝 의향서 · 💰 대출요청/조건제시

- **인수·임차의향서** — 대상 물건(목록 선택 또는 직접 입력), 매입/임차, 희망 가격·임차면적·임대료·시기, 회사·성명·연락처·메모 → `lois`
- **대출요청 · 대출조건 제시** — 대상 물건, 구분(대출요청/대출조건 제시), 금액·LTV·금리·만기·트랑슈(선/중/후순위), 담당자 → `loans`
- 두 폼 모두 **모든 권한**에서 제출할 수 있고, 접수 내역 조회는 관리자만 가능합니다(제출자 연락처 보호).

### 📄 TM / 📘 IM 제작 연동

물건 상세 패널과 홈의 `TM 제작`·`IM 제작`에서 **NAI Korea 양식 브리프 미리보기**(표지 · Deal Overview · 위치/스펙 · 임차·수익 · 투자 포인트)가 열리고,
같은 순간 `doc_requests`에 **제작 요청(물건 ID·양식·요청자·일시)** 이 기록됩니다.
미리보기는 `🖨 인쇄 / PDF 저장`으로 그대로 PDF로 저장할 수 있고, 제출용 `.pptx`는 로컬 생성기로 만듭니다.

```bash
# 비공개 시트의 물건 ID로 TM·IM(.pptx + .pdf + 미리보기 PNG) 생성
python3 work_tm_im/generate_tm_im.py --asset-id <물건ID> --token "$NAI_TOKEN" --kind BOTH --preview
python3 work_tm_im/generate_tm_im.py --json <물건 JSON> --kind TM --preview
```

### 홈 API (Apps Script v6 · `Home.gs`)

- `GET ?type=articles|notices` — 전 권한(비공개 글·작성자 제외)
- `GET ?type=lois|loans|doc_requests|proposals` — 관리자 전용
- `POST {action:'submit_loi'|'submit_loan'}` · `{action:'request_doc', doc_type:'TM'|'IM'}` · `{action:'submit_asset', proposal:{…}}` — 전 권한(신원·권한은 세션에서 기록)
- `POST {action:'article_save'|'article_delete'|'notice_save'|'notice_delete'|'proposal_approve'|'submission_status'}` — 관리자 전용
**`Open AI Asset Bridge`**는 NAI Korea 물건 DB를 기반으로 만든 프로토타입입니다.
빌드 도구 없이 정적 파일만으로 동작하며, GitHub Pages에서 서빙됩니다.

- 배포 주소: <https://rnjswnsdh-lab.github.io/Jk-asset--map/>
- 접속은 **4단계 권한**입니다. 코드/인증이 없으면 물건 데이터는 1건도 로드되지 않습니다.
  - **관리자** — 조회 + 수정·추가·삭제 + 저장 + 메일 발송
  - **내부 CM팀**(내부 CM팀 코드 · 별도 전달) — 전체 조회 + VDR·SI·FI 등록. 전화번호는 서버가 `비공개`로 가림
  - **물류TF**(물류TF 코드 · 별도 전달) — 물류센터 섹터·화주 풀·화주 CRM 만. VDR·FI·SI 차단
  - **외부 방문자** — 리멤버 명함 인증(또는 신규 등록)으로 발급된 세션. 조회·시뮬레이션만 가능하고
    담당자 컨택포인트(이름·직책·이메일·전화)는 서버가 내려주지 않으며 메일 발송 바가 숨겨집니다

## 동작 방식

1. 첫 화면에서 접속코드를 입력합니다.
2. 브라우저가 코드를 SHA-256으로 파생해 접근 토큰을 만들고, 그 토큰을 이 브라우저의
   `localStorage`에만 저장합니다. 코드·토큰의 평문은 소스에 없습니다.
3. 토큰이 유효하면 Google Apps Script 웹앱(비공개 Google 시트)에서 물건 목록과 권한(`role`)을
   받아 카카오맵 마커와 목록으로 렌더링합니다.
4. 관리자 권한에서 수정·추가·삭제하면 같은 API로 시트에 즉시 반영되고, 실패 시 브라우저
   대기열에 남겨 두었다가 다음 접속 때 다시 전송합니다.

### 저장 규격 (§DISC)

공시 값은 공개 저장소에 두지 않고, 비공개 시트 `assets` 의 각 행 `facts` 칸에만 저장합니다.

```jsonc
// facts 배열의 한 원소
{"label":"§DISC","value":"{\"k\":\"K-REITS\",\"s\":\"출처\",\"a\":\"기준일\",\"t\":\"제목\",\n  \"kv\":[[\"라벨\",\"값\"]],\"li\":[[\"텍스트\",\"URL\"]],\"u\":\"원문URL\",\"n\":\"비고\"}"}
```

`§DISC` 항목은 상세 패널의 공시 섹션으로만 렌더링되고 **`상세 스펙` 표에서는 제외**됩니다.
재실행하면 해당 물건의 `§DISC` 항목만 교체됩니다(멱등).

## 보안 메모

- 이 저장소에는 **물건 데이터가 포함되어 있지 않습니다.** 데이터는 비공개 Google 시트에만 있습니다.
- 접속코드와 접근 토큰은 저장소에 커밋되지 않으며, 사용자가 화면에서 직접 입력합니다.

  서버에서 필드를 지운 뒤 내려줍니다.
- 앱은 엣지(Edge)·크롬·사파리 최신 버전에서 동작합니다. 접속코드 파생에 Web Crypto를 쓰므로

### 5) 📱 PWA — 홈 화면에 추가
`manifest.webmanifest`(display: standalone · theme #0b2a4a · 아이콘 192/512 maskable) + `apple-touch-icon` + `theme-color`.
- Android Chrome: 메뉴 → **홈 화면에 추가** / iOS Safari: 공유 → **홈 화면에 추가** → 네이비·골드 브리지 아이콘으로 실행
- 시작 URL `./?src=pwa` (설치 여부 추적용)
